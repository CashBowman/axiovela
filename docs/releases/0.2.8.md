# Axiovela 0.2.8

## Library keyboard navigation

- Use Up/Down on a Library item to select the previous/next visible source or research result. Home/End select the first/last item, without wrapping.
- Navigation follows the displayed groups and current search, type and reading-status filters. Selection, keyboard focus and the reader update together; the item scrolls into view.
- Tab enters the selected visible item, or the first visible item when filtering hides the selection. Filtering alone preserves the current reader and reading position.
- Read checkboxes remain independently keyboard-accessible. Search, chat, PDF reading, modified shortcuts, annotations and connections keep their existing behavior.

## Validation and delivery

Isolated browser fixtures cover all science/engineering groups, reader updates, focus, boundaries, filters, empty results, independent input keys and Space-to-toggle reading status. Packaged Linux checks cover Library navigation, annotation/clipboard/PDF behavior and native launch/relaunch. The local release gate, desktop and annotation tests, and clean-install check are included.

All six OS/CPU targets and 13 package formats are assembled locally. Mac bundles are freshly ad-hoc signed; Windows retains unsigned distribution. Final Mac/Windows and Linux ARM64 payloads are verified on Linux without new native execution on those systems. No GitHub build is used. Installation remains manual; save work and quit Axiovela before installing.
