# Axiovela 0.2.0

This release adds browser-style project tabs above the toolbar, expanding chat
drafts, collapsible sent prompts, copying for prompts and responses, queued
follow-ups, and clearer provider activity. Research context is retrieved as
needed instead of automatically loading unrelated experiment results.

Provider setup buttons launch supported installation and sign-in commands in the
system terminal. Bibliography sits with the write-up controls. Markdown and
LaTeX documents offer separate source and PDF exports. The first LaTeX render
allows up to four minutes for initial TeX downloads and reports a clear timeout
when the download or compilation exceeds that limit.

## Downloads

[Versioned release assets](https://github.com/CashBowman/axiovela/releases/tag/v0.2.0)
cover Linux x64 (DEB, RPM, portable ZIP), Windows x64 (Setup.exe and ZIP),
Apple Silicon Mac (DMG and ZIP), and Intel Mac (DMG and ZIP). Match the
architecture and verify the SHA-256 manifest. Windows/Linux ARM64 installers
are not part of the supported build matrix. Keep the previous installer for
rollback; projects and settings retain their existing locations.

## Verification

All four native build/test targets passed: Linux x64, Windows x64, Apple Silicon
Mac, and Intel Mac. The exact Mac DMGs also passed on macOS 26 for both
architectures. Clean source installation passed on Linux, Windows, and macOS.
The release includes validation and build-provenance records and a SHA-256
manifest. Windows tests exercise the packaged app, not a downloaded Setup.exe
installation in an ordinary user account.

These unchanged installers were built and tested before the public source
snapshot was created. Historical development commits and CI logs remain private;
public release records preserve the reported results without publishing that history.

Mac builds are ad-hoc signed and unnotarized; Windows installers are unsigned.
Native automated tests do not establish OS publisher trust, live provider
accounts, or every hardware configuration. Provider login still requires user
interaction and npm-based setup requires Node/npm. Queued follow-ups are
supported; simultaneous worktree runs and native in-flight steering are not.

Source and downloads are public under the MIT license and accompanying notice.
Mac automatic trust assessment was rejected; notarization is not established by
passing functional tests.
