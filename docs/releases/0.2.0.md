<details>
<summary>Not sure which download to choose?</summary>

- **Mac:** open Apple menu → About This Mac. “Chip: Apple M…” means Apple Silicon; “Processor: Intel…” means Intel.
- **Windows:** the installer is for Intel/AMD 64-bit PCs.
- **Linux:** choose DEB for Ubuntu/Debian or RPM for Fedora-compatible systems.

Windows and Linux ARM installers are not available. [Installation help](https://github.com/CashBowman/axiovela/releases/download/v0.2.0/START-HERE.txt).

</details>

## What’s new

- Top-level project tabs and chat copying, expanding drafts, and queued follow-ups.
- Context retrieved when needed, clearer activity, and provider setup buttons.
- Bibliography beside your writing, plus separate source and PDF exports.

<details>
<summary>Validation and technical details</summary>

All four native build/test targets passed. The same Mac DMGs also passed on macOS 26 for both architectures; clean source installation passed on Linux, Windows, and macOS. These are the unchanged tested installers. Prior development history remains private.

[Validation record](https://github.com/CashBowman/axiovela/releases/download/v0.2.0/VALIDATION.json) · [Apple Silicon assessment](https://github.com/CashBowman/axiovela/releases/download/v0.2.0/MAC-TRUST-arm64.json) · [Intel Mac assessment](https://github.com/CashBowman/axiovela/releases/download/v0.2.0/MAC-TRUST-x64.json)

Functional tests do not establish publisher trust or every device/provider configuration. Mac automatic trust assessment was rejected. Windows testing exercised the packaged app, not a downloaded Setup.exe installation in an ordinary user account. Live provider accounts were not tested by the automated fixtures.

Sign-in remains interactive. Follow-up queueing is supported; simultaneous worktree runs and native in-flight steering are not. Keep project backups before updating.
