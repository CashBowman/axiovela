# Axiovela 0.2.17

Fixes severe typing delays in the main chat box when a project contains detailed experiment records. The app now reuses unchanged metric tables, avoids repeatedly parsing ordinary metric labels, and pages large tables while keeping every recorded value accessible.

An isolated local replay of an affected project improved an 18-character typing sequence from 15.6 seconds to 78 milliseconds. This is a measured result on the Linux test machine, not a guarantee for every device. The previously released PDF annotation focus fix is included.

All 13 application packages were built locally; no GitHub build workflows were used. Windows packages are unsigned. Mac packages are freshly ad-hoc signed without Developer ID signing or notarization. Linux x64 launch/relaunch is tested locally; native Windows, macOS and Linux ARM64 execution remains untested for these artifacts.

Save your work, finish active tasks, quit Axiovela, then install the matching package. Existing projects and profile data remain separate from application files. Installation remains manual.
