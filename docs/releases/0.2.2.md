# Axiovela 0.2.2

[Download the stable release](https://github.com/CashBowman/axiovela/releases/tag/v0.2.2).

## Keep research moving in parallel

Run experiments, write manuscripts, and explore separate projects concurrently. Switching tabs keeps active tasks running; new conversations can begin immediately. Follow-ups remain ordered within their own conversation and continue in background tabs. Stop one chat independently, track active work across projects, and reconnect to running tasks after a renderer reload.

This release also introduces flat section navigation, project-scoped request handling, independent status polling, and accurate Pi streaming/tool activity. Guided update checks from 0.2.1 remain available.

See [the parallel chat guide](../parallel-chats.md) for workflow details and shared-file/queue boundaries.

## Builds and installation

Targets are macOS ARM64 (Apple Silicon) and x64 (Intel), Windows x64 and ARM64, and Linux x64 and ARM64. Windows ARM64 uses a portable ZIP with native ARM64 Electron; its bundled x64 Tectonic PDF engine uses Windows emulation. No universal binary or every-device acceptance is implied.

The GitHub release records final artifact hashes and native build/test results. The maintainer accepted the parallel workflow on Linux. Automated native tests use isolated projects and credential-free providers; they do not establish live-provider behavior on every machine.

Mac packages are ad-hoc signed, without Apple notarization; Windows packages do not carry an Authenticode publisher signature. Stable release status describes the release channel, not OS trust. Follow the [Mac installation guide](../mac-installation.md) and respect device policies.

Save work and finish active tasks before quitting and updating. Existing projects, saved formats, provider settings, and legacy command aliases remain compatible. Installation is manual; verified in-app downloads remain unavailable until release-signing keys are provisioned.
