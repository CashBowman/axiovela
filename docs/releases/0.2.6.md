# Axiovela 0.2.6

## Changes

- Library imports articles and PDFs, groups science/engineering results, and filters item types independently from reading status. Read checkboxes use a pale blue treatment.
- Sentence, passage and image annotations become editable, unsent chat attachments. Select text and copy normally; feedback saves only through Add to message (or its keyboard shortcut). Ordinary Send combines notes and instructions.
- A compact image feedback button appears at the bottom-right of gallery images, the enlarged viewer and rendered images. Existing enlargement, source navigation, zoom and scrolling remain available.
- Saved source identity and revisions prevent feedback being applied to changed documents or replaced figures. Projects and assistant conversations retain separate drafts, queues and running tasks.
- Projects menu reopens known folders in tabs. Explained cross-project connections expose recorded relationships and shared-source associations without merging files or claiming scientific conclusions.
- Substantial research maintains structured science/engineering records; graph edges expose explanations by click or keyboard. PDF fullscreen keeps a compact toolbar and reading position.

See [annotations and Library](../annotations.md), [project navigation and storage](../project-navigator.md), and the [Axiovela Math implementation prompt](../axiovela-math-project-navigator-prompt.md).

## Packaging and validation

This release is assembled locally without GitHub builds. Architecture-specific Electron and Tectonic runtimes are retained from reviewed packages, application code and lockfile dependencies are updated, and installer payloads are verified. Mac bundles receive fresh ad-hoc integrity signatures; Windows retains unsigned distribution. This is the existing distribution policy accepted by the maintainer.

Credential-free fixture checks cover the backend, actual Linux Electron UI, annotations, image feedback, Library filters, project navigation, native clipboard menus, PDF reading/zoom/fullscreen, conversation isolation, and desktop launch. Final macOS and Windows payload verification on Linux does not constitute a new native installation test of these exact final files; earlier beta testing was accepted by the maintainer.

Installation remains deliberate: save work, quit, and install the downloaded release. Existing guided updates verify downloads but do not replace a running app.
