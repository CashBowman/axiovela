# Axiovela 0.2.9

## Conversation history

- Search conversations within a project or across saved projects, including matching message excerpts.
- Rename, pin, archive and restore conversations. Manual titles survive follow-ups and restarts; provider handoffs retain the logical conversation.
- Upgrade conversation metadata with exact pre-upgrade backups. Existing experiments, results, manuscripts, figures and transcripts are preserved. See [conversation history and recovery](../conversation-history.md).
- Codex names synchronize on the next turn. External providers control their own sidebar grouping.

## Keyboard navigation

- Trials: Up/Down selects the previous/next recorded trial; Home/End selects the first/last. The record, focus and scroll position follow selection, without wrapping.
- Figure cards: arrow keys move focus in displayed group order; Home/End reaches the ends. Enter opens the focused figure. Existing viewer Left/Right navigation remains available.
- History results: Up/Down and Home/End move focus on the current result page. Enter opens the chosen conversation and project. Arrows alone do not switch projects.
- Workspace sections: Left/Right and Home/End select a section. Search, editors, modified shortcuts and secondary action buttons retain their own keyboard behavior.

## Local builds and validation

All application assembly and installer packaging take place locally. No GitHub build is dispatched. Linux x64 is executed in isolated fixtures; Windows and Linux ARM64 packages retain reviewed architecture-specific runtimes and are checked for payload, CPU and version consistency. Their final native installation is not newly validated on this Linux host. Windows installers remain unsigned.

Mac x64/ARM64 candidates are assembled and freshly ad-hoc signed locally, but withheld from this release pending the required native Mac distribution check. Linux inspection cannot establish Gatekeeper trust, notarization, or native installation success.

Installation remains manual. Save work and quit Axiovela before installing. The update downloads do not install or replace a running app.
