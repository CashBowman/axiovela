# Axiovela 0.2.5

The 0.2.5 installers were refreshed to include in-place figure editing instructions and live figure preview updates. Presentation edits reuse existing plotting source and saved results, replace the same export and metadata entry, and preserve recovery copies outside the gallery. Gallery cards and an open viewer refresh when the file changes. Assistant instructions guide behavior but do not guarantee every provider's compliance.

If you installed 0.2.5 before this refresh, download the matching package again, save work and quit, then reinstall. The version remains 0.2.5, so the updater will not offer this as a newer version. Current checksums and build provenance identify the refreshed packages.

Fixes confirmed beta reports: Axiovela could close Pi after an intermediate WebSocket error, preventing native retry/context recovery. Pi now remains connected until the session settles, including in Full-access Agentic mode. Older Pi uses an idle-state check guarded by retry/compaction events. Exhausted failures remain visible; Axiovela does not independently replay a possibly executed prompt.

Agentic mode restores per conversation and agrees with its running task, preventing a reopened conversation from silently switching future prompts back to ordinary Pi.

Queued messages now appear beside the composer with explicit status and in-place Edit/Remove controls. Editing preserves attachments, settings and the separate composer draft. Later messages cannot overtake an edited item. Errors and Stop pause queues instead of deleting them; queued edits survive reopening and require Resume queue. Unconfirmed submissions remain available for review.

Verified update downloads work from 0.2.4. Older builds need one manual upgrade; installation remains manual. All six OS/CPU targets are packaged locally from retained native runtimes, without GitHub builds. Prior native validation and final local artifact checks remain distinct in the release validation record.

Protocol reference: [Pi RPC completion and retry events](https://pi.dev/docs/latest/rpc).
