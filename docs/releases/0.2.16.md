# Axiovela 0.2.16

PDF passage highlights now draw before the Leave feedback popup can receive focus. Clicking the feedback field and typing no longer exposes the gap between native selection and the persistent annotation highlight.

Regression checks cover immediate popup focus, typing with a visibly painted PDF highlight, and existing annotation workflows.

All builds were created locally without GitHub build workflows. Windows packages are unsigned. Mac packages are ad-hoc signed without Developer ID signing or notarization. Linux x64 is tested locally; native Windows, macOS and Linux ARM64 execution remains untested for these artifacts. Installation is manual; existing project and profile data must be preserved.
