# Axiovela 0.2.10

Codex sessions managed by Axiovela receive best-effort sidebar cleanup after their matching root turn completes. Cleanup requires an idle/unloaded root and a bounded check with no other loaded threads. Unsafe, pinned, unsupported or failed checks skip cleanup; completed output remains available.

Axiovela History stays visible and persistent. Follow-ups resume the original native session, restoring it only after an explicit archived-session rejection. Conversations, provider history, projects, permissions and queued follow-ups are preserved. Active sessions may temporarily appear in Codex Recents. Restart an already-running app after manually installing the update.

Built locally without GitHub builds. Linux x64 receives isolated packaged runtime checks. Windows and Linux ARM64 packages are checked for application payload, architecture and version; final native installation on those platforms is not validated on this Linux host. Windows installers remain unsigned. Mac candidates are withheld until the required native Mac distribution gate passes.

See [conversation history](../conversation-history.md) for protocol limits, backup behavior and validation.
