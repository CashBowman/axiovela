# Axiovela 0.2.14

A compact Usage button beside chat Access shows the latest reported conversation context and remaining account allowance. Click for token counts, quota windows, reset times and snapshot time. Codex provides root-conversation context and account quota snapshots; Pi provides context when available. Other connections explicitly show unavailable measurements. Context is not cumulative billing, and account allowance is shared across conversations. Changing provider/model hides the previous selection's measurements. No paid requests or credentials are needed for fixture checks.

Figure gallery cards and the enlarged viewer now offer a right-click action menu and a visible “…” button. Keyboard users can use Shift+F10 on a card. Removal previews the selected path and matching reference files, checks the file revision, then moves the figure to `.axiovela-trash/figures/` within its project. Undo and Removed figures → Restore recover it without overwriting newer work. Active project tasks block removal/restoration. Code, metadata, write-ups and conversation history are preserved; a separate action drafts a cleanup review in chat without sending it. Literal filename matching is bounded and does not certify every dependency. This release deliberately does not automatically delete shared generating code or rewrite discussions.

Built locally without GitHub Actions builds. Linux x64 is checked with isolated fixture projects. Windows packages are unsigned; Mac bundles use local ad-hoc integrity signatures without Developer ID or notarization. Cross-built payload checks do not establish native Windows/macOS launch or OS trust.

Interaction references: [specific consequences and recovery](https://www.nngroup.com/articles/confirmation-dialog/), [accessible menu keyboard controls](https://www.w3.org/WAI/ARIA/apg/patterns/menu-button/), and [Codex usage protocol](https://learn.chatgpt.com/docs/app-server).
