# Axiovela 0.2.18

PDF dragging now highlights the exact selected passage. Page-relative highlight geometry survives feedback focus, zoom and page unloading. Select area supports equations and figures with unreliable PDF text extraction, preserving the selected region and labeling extracted text as approximate. Existing annotations, independent drafts and source-revision checks remain intact.

The PDF.js renderer and LaTeX compiler are unchanged. Rendering stays limited to nearby pages; typing does not rerender the PDF. Real two-column LaTeX regression coverage includes fractions, integrals, matrices, superscripts and ligatures at 1×/2× display scales with 4× CPU throttling.

Built locally without GitHub Actions. Linux x64 launch/relaunch is validated locally; other supported platform/architecture packages are cross-built and structurally checked. Windows packages are unsigned; macOS packages receive fresh ad-hoc signatures and are not notarized. Native execution of those targets remains pending. Updates remain manual.
