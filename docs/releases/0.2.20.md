# 0.2.20: unified Methods and executive Study brief

Methods and Trials are now one **Methods** page. **Trial ledger** is upper left, **Experiment outline** is below it, and **Trial record** occupies the middle column beside chat. Trial selection drives both views. The outline focuses on the question and procedure; the record retains exact metrics, parameters, environment, artifacts, failures and supported cancellation.

Removed the Project setup, Experiment record and Execution log panels. Saved run records, diagnostic logs and infrastructure files remain intact.

The Study brief is a qualitative executive takeaway, limited to sixty words, covering the result, essential caveat and next decision. It omits numbers, counters, metric tables and separate findings/next-step lists. The assistant is instructed to stop generating redundant panel prose. Long, numeric or stale existing briefs remain saved and show neutral status until updated; the app never strips numbers from a claim or calls a model merely to rewrite an old brief. Exact evidence stays in Methods and figures. Actual token or latency savings have not been benchmarked with paid model calls.

Built locally without GitHub build jobs. Linux x64 is launch-tested locally. Windows, macOS and other architectures are cross-built and payload-verified, with native execution pending. Windows packages are unsigned; Mac bundles receive fresh ad-hoc signatures without Apple notarization. Preserve application data and research folders when installing. Previous versions remain usable for rollback.
