# Axiovela 0.2.3

Pi Agentic monitoring no longer queues slow Herdr checks behind one another. Quiet tool and worker waits are distinguished from a failed status connection; real progress and worker changes refresh activity. Parallel chats retain independent polling, queues, and cancellation.

Signed update metadata and a pinned public key enable verified update downloads for all six platform/CPU targets. The format picker offers only available installers, including the Windows ARM64 portable ZIP. Existing 0.2.2 and older installations require one manual update to receive the key. Installation remains guided and manual.

Final packages were assembled locally from retained native runtimes, with refreshed application code/version/configuration and fresh ad-hoc Mac signatures. No GitHub builds were started for this release. The maintainer authorized shipping after their prior installation acceptance. Build provenance and validation distinguish prior native tests from checks of these final local packages.
