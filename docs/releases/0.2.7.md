# Axiovela 0.2.7

## Changes

- Open passage and figure feedback beside its selection on the first visible frame. Reopen saved notes beside their pins, keep native copying and focus without scrolling, and clamp feedback to the viewport.
- Reuse unchanged Markdown/math rendering while typing. Keep source, bibliography, display mode, callbacks and image revisions current. Skip unchanged assistant snapshots and annotation overlay measurement loops.
- Refresh replaced figures in write-ups and chat without rebuilding unchanged content.
- Use restrained blue-gray scrollbars in the light workspace, preserving system high-contrast settings.

24 stored math-heavy chat turns (288 equations) and a 70-section document (140 equations), Linux x64 Electron, a 1560 × 1000 outer window. Each run types the same complete sequence with a CPU profiler attached; no providers or paid model calls.

| 18 chat characters | 7,789 ms | 214 ms |
| 22 annotation characters | 129 ms | 90 ms |

These are local whole-sequence timings, not per-keystroke latency or INP, and are not a general speed guarantee. Earlier after-runs measured 274 ms / 111 ms and 196 ms / 88 ms. CPU profiles, screenshots and raw measurements are retained in the local release evidence.

## Validation and delivery

Focused rendering tests cover source edits, bibliography changes, streamed text, callback freshness, image mappings and same-path figure replacement. Annotation fixtures cover explicit attachment/send, copy/paste/context menus, stale revisions, PDF scrolling/zoom/fullscreen and reader position. Parallel fixtures preserve conversation/project isolation, queues, permissions, cancellation and reload recovery. Packaged Linux launch/relaunch and clean installation are checked locally.

All installers are assembled locally from the existing architecture-specific runtimes with updated application code. Mac bundles receive fresh ad-hoc signatures; Windows installers retain the existing unsigned distribution. Final Mac/Windows installers and Linux ARM64 are payload-verified on Linux, without new native execution of those exact files. No GitHub build is dispatched.
