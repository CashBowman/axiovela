# Axiovela 0.2.11

Double-clicking a compiled LaTeX PDF now focuses and selects the corresponding line in the raw source editor. Axiovela records SyncTeX mappings during compilation and preserves line alignment when it prepares project figures for the renderer. Re-render after changing the source before using the mapping.

This release also includes the 0.2.10 session-continuity changes: guarded cleanup of completed Axiovela-managed Codex sessions from native Recents, persistent Axiovela History, archived-session recovery, nonfatal title synchronization, and preservation of logical IDs, native transcripts, permissions and queued follow-ups.

All installers were built locally without GitHub builds from the tagged public source. Linux x64 received isolated packaged runtime checks. Other targets were rebuilt from retained architecture-specific runtimes and checked for source parity, architecture, version, container integrity and installer payload integrity. The maintainer approved publication based on prior native acceptance and this focused source change. Windows installers remain unsigned. Mac applications are freshly ad-hoc signed but are not Developer ID-signed or notarized; OS trust prompts and managed-device policy may still block them.

Existing projects, conversations, settings and data formats remain compatible. Save work, finish active tasks, quit Axiovela, and install the new version manually. Restart any already-running copy after installation.
