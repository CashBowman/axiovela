AXIOVELA 0.2.2 — APPLE SILICON
Ad-hoc signed; not notarized.
For Macs with an Apple M-series chip, running macOS 13 or later

INSTALL
Download Axiovela-0.2.2-darwin-arm64.dmg from the link supplied by the maintainer.
Quit any older Hypotera or Axiovela app first. Open the DMG, drag Axiovela into Applications,
and open it from Applications. Confirm Help → About Axiovela shows 0.2.2.
Remove the old Hypotera.app from Applications after installing Axiovela.
Keep your project backups. Updating the app does not require deleting your profile.

This release has an ad-hoc integrity signature. It is not Developer ID-signed or notarized. If macOS blocks a
trusted, unchanged download with an unverified-developer warning, first try opening
it once, then go to System Settings → Privacy & Security → Open Anyway and confirm
Open, if available. macOS remembers the exception; a new download or update may
need approval again. GitHub hosting does not remove this requirement.
Apple's per-app instructions:
https://support.apple.com/en-us/102445
Do not disable system security. Stop and report malware/damage warnings or
institutional restrictions.

FIRST 15 MINUTES
1. Choose Help → Try the example study and inspect Results and Write-up.
2. Choose Project and create a disposable research folder.
3. Connect your own provider using the model selector below chat. Review access
   permissions before asking it to do a small task. Provider charges may apply.
4. Save a Markdown write-up, check its Draft indicator, insert a figure at the
   cursor, quit, and reopen. Inspect recorded experiments in Trials.
5. Try a LaTeX draft. Tectonic is included; its first render needs internet access
   for TeX packages and fonts. Tools → Check installed tools shows discovery.

6. Choose Link dataset and import a file or data folder. Try a PDF or MP3 if relevant.
   The chat paperclip offers the same choices. Originals are copied, not moved.
   Importing a format does not install its analysis libraries or grant a model
   native audio/PDF understanding. Use disposable data for your first test.

You do not need Git, Node, npm, or a GitHub account for basic desktop use.
Native assistant CLIs, Pi/Herdr, Python, and experiment libraries are separate
installations. Help → Optional tool setup explains the prerequisites.
Select Agentic mode to start an installed Herdr server automatically. If Pi or
Herdr is missing, the setup dialog provides installation commands and Retry.
For the simplest first session, use the example or a direct API connection.
