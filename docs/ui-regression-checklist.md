# Interface regression checks

Saving checks: type into each source format without pressing Save, wait for All changes saved, then reload and confirm text/format persistence. Simulate an assistant disk update and verify a clean editor refreshes. Edit during an active fixture task and change the disk source: the editor must preserve its recovery draft and expose a conflict, with Export source and confirmed Reload disk source as recovery options. Render a fixture using literal graphicspath directories and open the raw source link; neither should fall through to the UI-build error.

Run `npm run build`, then `node scripts/research-smoke.mjs --serve`. The latter starts an isolated, disposable project at `http://127.0.0.1:8896` using a deterministic CLI fixture, without credentials or live model calls. Stop it with Ctrl+C to remove its temporary files. Never point these test writes at a real research project.

Figure organization: run `node scripts/figure-organization-smoke.mjs`. In the UI, verify All experiments initially shows every figure; selecting Understanding the baseline shows only its linked figure and Model checks heading, and No run linked shows the legacy comparison. Enlarge must browse only filtered figures. Check the selector and headings in Write-up and at a narrow viewport. The project-wide brief must not change when filtering figures.

1. Results shows counts before the question, Markdown findings, a model-by-metric table, and a full-height two-figure gallery. Methods has an experiment selector, procedure (or missing-procedure notice), parameters, artifact paths, full metric tables, and logs, not another executive brief/gallery. Both nested objects and legacy dictionary strings must become tables; Exact recorded values preserves the source. Check narrow screens for table-local scrolling. Project setup merges configuration and code; Trials presents saved records in a compact ledger with expandable details and backend-owned cancellation. Check that Draft/Empty indicators update for both write-up formats after external edits.
2. Send `FIXTURE_LONG_CHAT` in either chat. The fixture returns twelve Markdown sections with equations, links, lists, and code. Messages must have natural heights, not overlapping rows. Scroll up: Jump to latest appears. Send a follow-up: the new user message and response appear below the previous reply. Reload: durable history retains the same order.
3. Figure cards should have no Size slider. Captions must remain visible below each image. Enlarge a figure; test arrows, thumbnail selection, zoom, scroll-to-pan, Fit, original download, and Escape/focus restoration. The modal should remain stable while background project polling continues.
   Check Figures from: All experiments includes unlinked figures; an experiment includes its variants; a run includes shared comparisons. Topic headings and run labels remain readable on narrow screens. Enlarge browses only the filtered figures in their displayed order. Filtering must not change the project-wide brief or project files. Verify the same selector in Write-up.
4. In Write-up, drag the assistant/figures divider downward beyond the previous 46% limit. Also focus the divider and press Up/Down. Insert a figure using the separate insertion action. Send a writing task: source must be saved first and still contain the figure afterward. New local edits made during the task must not disappear on completion.
5. Confirm Link dataset stays enabled during a running chat task. Link dataset: upload a disposable CSV or import an absolute local CSV path. Preview shows its content; Unlink removes it from the catalog while preserving the workspace copy. The source file must remain unchanged. Unsupported files, oversized uploads, and inaccessible paths should produce errors without losing the rest of the catalog.
6. At desktop (1920×1080), laptop (1280×900), and narrow (390×844) sizes, verify usable controls and no horizontal page overflow. On narrow screens, dataset import and bibliography controls remain available. Restore the browser viewport afterward.

7. Create two chats with New chat. Give each a different prompt; switch back and confirm its earlier messages remain and its next turn resumes the same native session. Unsent draft text and attachments should remain separate when switching; reload should preserve the selected conversation and saved messages. Repeat in the Research Assistant. Empty newly created chats should also survive reload.
8. Send `FIXTURE_CODE`, click Copy, and confirm the PowerShell code is selectable and the button reports Copied. Send `FIXTURE_HANG`: only one current activity line should appear, with no repeated event list. Open Link dataset during the task, close it, then Stop task.

Automated coverage complements these visual checks: `npm run research:smoke` exercises datasets, metadata, links, HTTP origin protection, and source-save conflict behavior; provider/session and backend smoke scripts cover the existing runtime and runner contracts.

9. Access appears beside the model picker below the composer in both roles, with no unused access row above chat. Drag a figure into the composer; verify its chip, remove/re-attach, send, and reload to confirm the saved reference. Test supported-mode restrictions and narrow widths.
10. A fresh writing conversation receives existing run IDs/metrics and figure metadata (credential-free FIXTURE_PROMPT). Missing briefs automatically show recorded facts; in-flight runs with empty metrics do not concatenate title and footnote. Equal timestamps with different offsets must not trigger a stale warning; a genuinely later completed run must.
